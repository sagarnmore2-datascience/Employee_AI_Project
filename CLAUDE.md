## Development Commands
The project currently consists of standalone Python scripts.
- Run a module: `python Employee_AI_Project/<file>.py`

## Architecture
The codebase is a skeleton for an AI-powered employee management system:
- `app.py`: Main entry point for the application.
- `dashboard.py`: Handles data visualization and dashboarding.
- `database.py`: Manages database connections and operations.
- `rag.py`: Implements Retrieval-Augmented Generation (RAG) logic.
- `utlis.py`: contains shared utility functions.
